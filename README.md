# Social-Nonsocial-Learning-CU-Children

"SPARK Zoo" is a developmentally appropriate probabilistic reversal-learning task for children aged 4 years and above, designed to investigate how children learn from and adapt to social and non-social feedback with varying ambiguity in changing environments.

The task is implemented in Python using PsychoPy 2022 and is designed to be compatible with EEG recordings. It takes approximately 8 minutes to complete and includes both social and non-social outcome conditions.
